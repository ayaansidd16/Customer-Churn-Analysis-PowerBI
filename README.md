# 📊 Customer Churn Analysis | Power BI

An interactive Power BI project focused on analyzing customer churn patterns, understanding customer behaviour, and identifying factors that influence customer retention.

## 📌 Project Overview

Customer churn is an important challenge for subscription-based businesses. This project analyzes customer data to understand why customers leave and which factors are associated with higher churn rates.

The dashboard provides visual insights into customer demographics, service usage, payment methods, contract types, and monthly charges.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Measures & Calculations)
- Data Visualization
- Data Analysis

## 🔍 Key Insights

- Month-to-month contract customers show significantly higher churn.
- Electronic check users represent a major portion of churned customers.
- Customers without technical support show notable churn patterns.
- Monthly charges and customer tenure provide useful insights into customer behaviour.
- Senior citizen and paperless billing categories help explore demographic and billing-related churn patterns.
